## GitHub Pages公開

1.  GitHubで新しいリポジトリを作成
2.  このフォルダをアップロード
3.  Settings → Pages
4.  Source: Deploy from branch
5.  Branch: main
6.  数十秒後に公開

## 商品追加

`data/products.json`へ商品を追加してください。
