# 30秒 肌チェック

GitHub Pages で公開できる、依存関係なしの静的サイトです。10問のセルフチェックから肌の傾向に合わせて3商品を提案し、話題のスキンケア20商品を成分とともに掲載します。

## 公開方法

1. このフォルダを GitHub リポジトリへアップロードします。
2. GitHub の **Settings > Pages** を開き、`Deploy from a branch` と `main / (root)` を選択します。
3. 表示された URL を開きます。

## アフィリエイトリンクの設定

`js/app.js` 内の `YOUR_ASSOCIATE_TAG-22` を、ご自身の Amazon アソシエイト・トラッキングIDに置き換えてください。未置換のままでは有効な紹介リンクになりません。

掲載成分・仕様は変更される場合があります。公開前に各商品の公式ページとアフィリエイト規約をご確認ください。
