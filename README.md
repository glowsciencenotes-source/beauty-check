# 30秒肌診断

美容成分データベースを利用した無料の肌診断Webアプリです。

## 特徴

- 約30秒で診断
- 10〜20問の質問
- 肌タイプ判定
- 肌悩み分析
- おすすめ美容成分表示
- おすすめ商品表示
- レスポンシブ対応
- PWA対応
